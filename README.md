Two things hold my attention. One is how a national grid stays up, which is what
I trained for and what I have spent my working years on. The other is what
happens when software agents are given memory, money, and something to lose.
Most of what I build sits somewhere between those.


## Work

**Analyst, Engineering Performance and Monitoring**
Nigerian Electricity Regulatory Commission, Abuja

Built a real-time feeder monitoring system that ingests live distribution data
and maps feeder status geographically. Wrote predictive maintenance models in Python that lifted forecasting
accuracy, and a metering compliance dashboard in Power BI and SQL that cut report generation time by a quarter.

Before that, I trained at TCN's Abuja Regional Control Centre on the 330kV and
132kV transmission grid, working alongside control room engineers on load
dispatch, frequency regulation, and system disturbance analysis.
